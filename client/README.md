# Google Photos Clone — Frontend

The Next.js 16 client for the Google Photos Clone. Setup, architecture, screenshots and the full API reference are in the [project README](../README.md).

```bash
npm install
npm run dev      # http://localhost:3000 (expects the API at http://localhost:8080/api)
```

Set `NEXT_PUBLIC_API_URL` in `.env.local` to use a different API URL.
